# Local Font Licenses

This folder contains locally hosted copies of fonts previously loaded through Google Fonts.

- Inter: SIL Open Font License 1.1
- Poppins: SIL Open Font License 1.1
- Playfair Display: SIL Open Font License 1.1
- Roboto: Apache License 2.0

The font files are served from this theme to avoid runtime dependency on Google Fonts or fonts.gstatic.com.
