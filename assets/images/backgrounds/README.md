# Background images

Place optional background images in this folder. Rasamala scans the folder on
each request and adds each supported file as a Background Style choice.

Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.avif`, and `.svg`.

Use optimized images (recommended maximum around 1920px wide and 500 KB) so
the background does not slow down the OPAC. The animation layer remains above
the selected image.
